# 우월코드 (완료)

## 니케
- 코드는 총 다섯개 전격, 철갑, 작열, 수냉, 풍압
- 각 코드는 다음과 같은 상성을 가집니다.
    - 철갑 > 전격
    - 전격 > 수냉
    - 수냉 > 작열
    - 작열 > 풍압
    - 풍압 > 철갑
- 위 상성을 기준으로 상성 우위를 가질 경우 이를 우월 코드라고 칭하며 전격의 우월 코드는 철갑입니다.
- 위 상성을 기준으로 상성 열위를 가질 경우 이를 약점 코드라고 칭하며 수냉은 전격의 약점 코드 입니다.
- 우월 코드 보너스는 장비, 버프 등으로 추가될 수 있습니다.
- 모든 캐릭터는 고유의 우월 코드를 가지지만 일부 캐릭터는 두개 이상의 우월코드에 보너스를 받기도 하며 이후 업데이트로 인해 추가될 수 있습니다. 이 경우 해당 캐릭터의 원소 코드가 실제로 두개가 되지는 않으며 스킬 정보 등을 통해 별도로 해당 내용이 추가됩니다.

## 적
- 시뮬레이션 시 적의 약점 코드를 선택하여 우월 코드 보너스를 적용할 수 있습니다.
- 선택한 캐릭터들 중 우월 코드에 해당하는 캐릭터들의 경우에만 우월 코드 보너스를 적용합니다. 예를 들어 적의 약점 속성이 작열인 경우 수냉 캐릭터들은 우월코드 보너스를 받지 않습니다.

## 보너스
- 우월 코드 대미지 보너스는 기본값 1.1배의 데미지를 적용합니다.
- 우월 코드 대미지 보너스는 장비 또는 버프, 큐브로 인해 증가할 수 있습니다. 자세한 내용은 damage_formula.md를 참고합니다.
