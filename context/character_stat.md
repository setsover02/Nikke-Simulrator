# 캐릭터 기본 스탯

## 기본 정보
각 캐릭터는 다음과 같은 정보가 포함됩니다.
- characterID: 시뮬레이터 내부 코드에서 캐릭터들을 구분하기 위해 사용
- characterName: 캐릭터의 이름
- element: 캐릭터의 원소 코드(이하 코드라고 명칭)
    - 코드는 총 다섯개 전격, 철갑, 작열, 수냉, 풍압
    - 각 코드는 다음과 같은 상성을 가집니다.
        - 철갑 > 전격
        - 전격 > 수냉
        - 수냉 > 작열
        - 작열 > 풍압
        - 풍압 > 철갑
    - 위 상성을 기준으로 상성 우위를 가질 경우 이를 우월 코드라고 칭하며 전격의 우월 코드는 철갑 입니다.
    - 우월 코드 보너스는 장비, 버프 등으로 추가될 수 있습니다.
    - 모든 캐릭터는 고유의 우월 코드를 가지지만 일부 캐릭터는 두개 이상의 우월코드에 보너스를 받기도 하며 이후에 또 추가될 수 있습니다. 이경우 해당 캐릭터의 원소 코드가 두개가 되지는 않으며 스킬 정보 등을 통해 별도로 해당 내용이 추가됩니다.
- weapon: 캐릭터가 사용하는 무기, 무기는 총 6개 종류가 있으며 차지형과 일반형 두개의 타입으로 나눠집니다. 각 무기의 특징은 다음과 같습니다.
    - MG
        - 예열 시간 있음, 예열 시간 동안 명중률, 공격속도가 현저하게 낮으며 예열시간 이후에는 빠른공격속도 (60발/초)와 100% 명중률이 적용됩니다.
        > 공격 속도는 추후 다른 타입의 캐릭터가 나올수 있으므로 고정 값으로 적용하지 않습니다.
        - 
    - SMG
    - SR
    - RL
    - SG
    - AR



- class: 캐릭터의 클래스
    - 클래스는 총 3개 화력형, 방어형, 지원형
    - 각 클래스는 다음과 같은 특징을 가집니다.
        - 화력형: 공격력 증가
        - 방어형: 방어력 증가
        - 지원형: 체력 증가
        - 특수형: 공격력, 방어력, 체력 증가
- burstLevel: 캐릭터의 버스트 레벨
    - 버스트 레벨은 1, 2, 3이 있으며 버스트 스킬의 레벨을 결정합니다.

## 고유 스탯
각 캐릭터는 다음과 같은 기본 스탯을 가집니다.
- 공격력
- 방어력
- 체력
장비, 큐브, 소장품 등과 같은 외부 요인에 의해 다양하게 변경될 수 있으므로 이 값은 직접 입력하도록 합니다.

또 다른 고유 스탯은 다음과 같습니다.
- 장탄 수
- 재장전 시간
- 공격 계수 %
- 차지 시간
- 풀 차지 대미지 %
- 코어 대미지 %
- 발사 속도


- 크리티컬 확률
- 크리티컬 대미지
