# 니케 기본 스탯
캐릭터(Character)와 니케(Nikke)는 동일한 의미로 사용됩니다.

## 기본 정보
각 니케는 다음과 같은 정보가 포함됩니다.
- characterID: 시뮬레이터 내부 코드에서 캐릭터들을 구분하기 위해 사용
- characterName: 니케의 이름
- element: 니케의 원소 코드(이하 코드라고 명칭)
    - 코드는 총 다섯개 전격, 철갑, 작열, 수냉, 풍압
- weapon: 캐릭터가 사용하는 무기, 무기는 총 6개 종류가 있으며 차지형과 일반형 두개의 타입으로 나눠집니다.
    - MG: 일반형
    - SMG: 일반형
    - SR: 차지형
    - RL: 차지형
    - SG: 일반형
    - AR: 일반형
- class: 클래스는 총 3개 화력형, 방어형, 지원형
    > 클래스에 따른 특정 효과는 없으나 일부 스킬에 클래스에 따른 효과가 존재합니다.
- company: 니케의 제조사 정보
    - 엘리시온: Elysion
    - 테트라: Tetra
    - 미실리스: Missilis
    - 필그림: Pilgrim
    - 어브노말: Abnormal
    > 제조사에 따른 특정 효과는 없으며 이후 스킬에 추가될 가능성이 존재합니다.
- squad: 니케의 소속 부대 정보
    > 특정 스쿼드 또는 동일 스쿼드의 니케가 함께 팀을 이룬 경우 적용되는 버프가 존재합니다.
- burstLevel: 니케의 버스트 레벨 - 1, 2, 3
    > 1, 2, 3 버스트를 모두 사용할 수 있는 니케가 존재하며, 팀에 1버스트가 없는 경우 3버스트의 니케가 1버스트를 사용할 수 있도록 하는등의 예외 케이스가 존재합니다. 이는 각 니케의 스킬설명에 작성됩니다.

## 고유 스탯
각 니케는 다음과 같은 기본 스탯을 가집니다.
- atk: 공격력
- defense: 방어력
- hp: 체력
> 장비, 큐브, 소장품 등과 같은 외부 요인에 의해 다양하게 변경될 수 있으므로 이 값은 직접 입력하도록 합니다.

또 다른 캐릭터별 고유 스탯은 다음과 같습니다.
- maxAmmo: 장탄 수
- reloadTime: 재장전 시간
- atkCoef: 공격 계수 %
- chargeTime: 차지 시간
- fullChargeDamage: 풀 차지 대미지 %
- coreDamage: 코어 대미지 %
- fireRate: 1초당 발사 속도

전체 니케가 공통적으로 가지는 스탯은 다음과 같습니다.
- criticalRate: 크리티컬 확률 - 15%
- criticalDamage: 크리티컬 대미지 - 1.5배 데미지 적용

## 장비, 오버로드로 인해 변경되는 스탯
- atk: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.
- defense: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.
- hp: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.

아래의 값은 사용자가 장비 정보에 직접 입력하여 수치를 적용합니다.
- elementDamage: 우월코드 대미지 증가%
- accuracy: 명중률 증가%
- maxAmmo: 최대 장탄 수 증가%
- attackPower: 공격력 증가%
- chargeDamage: 차지 대미지 증가%
- chargeSpeed: 차지 속도 증가%
- criticalRate: 크리티컬 확률 증가%
- criticalDamage: 크리티컬 대미지 증가%
- defense: 방어력 증가%

## 소장품으로 인해 변경되는 스탯
소장품은 무기 타입 별로 별도의 스탯을 증가시켜주며 장비와 마찬가지로 공격력, 방어력, 체력은 직접 입력하도록 합니다.

## 스킬
각 니케는 다음과 같은 스킬을 가집니다.
- skill_1: 패시브 스킬
- skill_2: 패시브 스킬
- burst: 버스트 스킬

## 애장품으로 인한 스킬 변동
애장품은 각 니케의 스킬을 변동시킬 수 있습니다. 애장품을 적용할 수 있는 니케는 정해져 있으며 업데이트로 인해 종종 추가될 수 있습니다. 이 경우 새로운 json 파일을 작성하지 않고 애장품을 줄 수 있는 캐릭터에 애장품으로 인해 변동되는 스킬정보를 함께 작성합니다.
- 사용자는 시뮬레이션에서 해당 캐릭터의 애장품 적용 여부와 애장품 레벨인 1-3레벨을 선택할 수 있어야 합니다.
- 애장품 레벨에 따라 어떤 스킬이 변경될지에 대한 여부가 결정됩니다. 예를들어 애장품 레벨1 - 버스트 스킬 변경, 레벨2 - 스킬 1 변경, 레벨3 - 스킬 2 변경 등의 방식이며 애장품에 따라 레벨1이 스킬 2를 변경시킬 수도 있습니다.
