## 인게임 상황
1. 유레 (유니온 레이드) 는 노말 1일, 하드 1일 정도에 끝이 난다
2. 1일당 3번씩 칠 수 있으며, 1일차 노말 총 3회, 2일차 하드 총 3회, 즉 2일간 총 6회를 칠 기회가 있다.
3. 노말 난이도의 경우 50개의 보스를 모두 잡아야 하며 딜이 안정적이라면 유니온 전체 50회의 전투 기회 내에 끝난다. 그렇지 않을 경우도 50 ~ 60회 사이에 끝난다.
4. 만약 노말 난이도를 끝내지 못한 경우 노말 난이도가 2일차로 넘어가게 되며 하드는 3일차에 오픈된다. 이 경우 랭킹과 보상에 큰 문제가 생긴다. 노말이 1일 차에 끝나는 것이 굉장히 중요하다.

## 현재 유니온 규칙
1. 노말 1일과 하드 2일차의 6회중 3회 이하 2회부터 50% 미만 참여율인 경우 경고가 부여되며 경고가 2회 누적되면 추방한다.
2. 즉 유레 (1달 마다 열림) 시 2달 연속 참여율이 낮을 경우 추방된다.
3. 위 상황과 규칙이 현재 유니온 규칙이다. 여기서 다음 사항을 해결해야한다.

1. 노말 제외 하드 참여시 이른바 숟딜 참여가 문제가 된다. 제대로 딜을 넣지 않고 참여만 하는 경우 경고는 받지 않지만 딜이 너무 낮아 문제가 된다.
2. 숟딜 경고제를 도입할 예정이다. 하드 딜이 너무 낮으면 경고를 부여한다.
3. 하드 자체를 참여하지 않는 경우가 생길 수 있다. (평가할 딜이 없으므로 숟딜 경고 회피)
4. 하드 필수 참여를 권장하기에는 너무 빡셀 수 있어 고민이 된다. 다만 필요에 따라 필수 참여를 권장할 수 있음, 단 이 경우 노말 난이도를 아무도 참여하지 않을것 같다는 문제가 발생함
위 사항을 기반으로 새로운 규칙이 필요함

## 새로운 규칙안 (제안 v4)

> **v3의 문제**: 숟딜 경고만 있고 참여 의무가 없으면 하드 1회만 정상 딜 넣고 나머지 5회(노말 3 + 하드 2)를 안 쳐도 통과됨. **노말을 누가 치냐**는 문제 발생.
>
> **v4의 핵심**: 기존 참여 의무(3/6)를 되살리되, 숟딜 경고와 합쳐서 **경고 조건 1개**로 통합.

### 설계 원칙
- 규칙은 최대한 단순하게, 누구나 이해할 수 있어야 함
- 노말 1일차 클리어가 최우선
- 숟딜도, 숟딜 경고 회피도 막아야 함

### 규칙

#### 경고 조건 — 다음 중 **하나라도** 해당하면 경고 1회
1. **참여 미달**: 노말 + 하드 총 6회 중 **3회 미만** 참여
2. **숟딜**: 하드 미참여 또는 하드 전 회차 딜 기준 미달

- 1회라도 정상 딜을 넣었다면 숟딜 경고 없음
- 딜 기준은 운영진이 별도 공지
- 경고 **2회 누적 시 추방**
- 경고는 매 유레 시즌마다 **1회씩 소멸** (선택사항)

> **왜 이게 노말 참여를 유도하는가**:  
> 총 3회 이상 참여해야 하고(조건1), 하드도 반드시 쳐야 하므로(조건2),  
> 하드 1회만 치면 나머지 2회를 노말에서 채워야 함.  
> 결과적으로 **노말 참여가 자연스럽게 발생**.

### 요약 표
| 상황 | 결과 |
|---|---|
| 총 참여 3회 미만 | 경고 (참여 미달) |
| 하드 0회 참여 | 경고 (숟딜) |
| 하드 참여 + 모든 회차 딜 기준 미달 | 경고 (숟딜) |
| 노말 2회 + 하드 1회 + 정상 딜 | 문제 없음 ✅ |
| 노말 0회 + 하드 3회 + 정상 딜 | 문제 없음 ✅ |
| 경고 2회 누적 | 추방 |

### 시나리오 검증
| 행동 | 조건1 (참여 3회 이상) | 조건2 (숟딜) | 결과 |
|---|---|---|---|
| 노말 3 + 하드 0 | ✅ 통과 | ❌ 하드 미참여 | **경고** |
| 노말 0 + 하드 1 (정상 딜) | ❌ 1회뿐 | ✅ 통과 | **경고** |
| 노말 0 + 하드 3 (정상 딜) | ✅ 통과 | ✅ 통과 | **통과** |
| 노말 2 + 하드 1 (정상 딜) | ✅ 통과 | ✅ 통과 | **통과** |
| 노말 2 + 하드 1 (숟딜) | ✅ 통과 | ❌ 전 회차 미달 | **경고** |
| 노말 0 + 하드 0 | ❌ 0회 | ❌ 하드 미참여 | **경고** |

### 이 규칙이 해결하는 것
1. ✅ **숟딜 방지** → 하드 딜 기준 미달 시 경고
2. ✅ **하드 미참여로 경고 회피 방지** → 미참여 자체가 숟딜
3. ✅ **노말 참여 유도** → 3회 참여 의무 + 하드 필수 → 노말도 쳐야 함
4. ✅ **빡세지 않음** → 총 3회(노말+하드 자유 배분) + 하드 1회 정상 딜
5. ✅ **단순함** → 경고 조건 2개, 경고 풀 1개
