# 전투 순환 로직 (완료)
> 이 문서는 전투 시뮬레이터 구현을 위한 규칙 명세다.
> 각 니케의 개별 데이터(쿨타임, 버스트 레벨, 버프 수치, 재진입 여부, 풀버스트 시간 변경 트리거 등)는 별도 컨텍스트의 니케 JSON을 참조한다.

---

## 1. 용어 정의

| 용어 | 정의 |
|------|------|
| 니케 | 전투에 참여하는 캐릭터 유닛 |
| 자리(Position) | 1~5번의 고정 배치 슬롯. 버스트 우선순위 기준 |
| 일반 전투(Normal Phase) | 버스트 게이지를 충전하는 기본 페이즈 |
| 풀버스트(Full Burst Phase) | Level 3 버스트 발동 후 진입하는 특수 페이즈 |
| 버스트 게이지 | 100% 도달 시 버스트 체인을 시작시키는 자원 |
| 버스트 체인 | Level 1 → 2 → 3으로 이어지는 버스트 연쇄 |

---

## 2. 팀 구성과 자리 배치

- 팀은 최소 1명, 최대 5명의 니케로 구성된다.
- 각 니케는 1번~5번의 고정된 자리에 배치된다.
- 자리는 **버스트 사용 우선순위**를 결정한다. **번호가 낮을수록 우선순위가 높다.**
- 사용자가 별도로 버스트 우선순위를 변경하지 않는 경우 위 규칙에 따라 버스트를 사용한다.

### 버스트 우선순위 규칙
1. 동일 버스트 레벨에서 여러 니케가 사용 가능하면, **가장 낮은 번호 자리**의 니케가 우선 선택된다.
2. 상위 우선순위 니케가 쿨타임이면, 다음 순번 니케가 선택된다.
3. 이 규칙은 Level 1, 2, 3 모두에 동일하게 적용된다.

---

## 3. 버스트 시스템

### 3.1 버스트 레벨
- 모든 버스트 스킬은 Level 1 / Level 2 / Level 3 중 하나의 레벨을 가진다.
- 각 버스트 스킬의 쿨타임은 니케별 JSON에 정의된 값을 적용한다.

### 3.2 버스트 발동 조건
- 버스트 게이지가 **100%가 되었을 때만** 버스트 스킬을 사용할 수 있다.
- 게이지가 100%가 되면 버스트는 **자동으로 발동**된다. (수동 조작은 고려하지 않는다.)
- 게이지가 100%인데 버스트 스킬이 쿨타임이면, 쿨타임이 끝날 때까지 대기하며 게이지는 100%로 유지된다. 쿨타임 종료 후 발동한다.

### 3.3 버스트 체인 규칙
버스트는 반드시 **Level 1 → Level 2 → Level 3** 순서로 연결된다.
각 단계에서 버스트를 사용한 니케의 **버스트 및 스킬 버프**가 적용된다. (버프의 대상·수치·지속시간은 각 스킬 설명(JSON)에 정의된 값을 따른다.)

#### Step 1 — Burst Level 1
- 게이지가 100%가 되면, 쿨타임이 아닌 Level 1 니케 중 **우선순위가 가장 높은** 니케가 발동한다.
- 해당 니케의 버스트 및 스킬 버프가 적용된다.
- 발동 후 **최대 10초** 동안 대기 상태에 진입한다.
- 대기 시간 내에 쿨타임이 아닌 Level 2 니케가 존재하면 **즉시** 다음 단계로 넘어간다.
- 10초 내에 Level 2가 발동하지 못하면 체인은 종료되고, 일반 전투로 복귀하여 게이지를 다시 충전한다.

#### Step 2 — Burst Level 2
- Level 1 발동 후 대기 상태에서, 쿨타임이 아닌 Level 2 니케 중 **우선순위가 가장 높은** 니케가 발동한다.
- 해당 니케의 버스트 및 스킬 버프가 적용된다.
- 발동 후 **최대 10초** 동안 대기 상태에 진입한다. 이를 버스트 진입 단계 2단계 라고 한다.
- 대기 시간 내에 쿨타임이 아닌 Level 3 니케가 존재하면 **즉시** 다음 단계로 넘어간다.
- 10초 내에 Level 3가 발동하지 못하면 체인은 종료되고, 일반 전투로 복귀하여 게이지를 다시 충전한다.

#### Step 3 — Burst Level 3
- Level 2 발동 후 대기 상태에서, 쿨타임이 아닌 Level 3 니케 중 **우선순위가 가장 높은** 니케가 발동한다.
- 해당 니케의 버스트 및 스킬 버프가 적용된다.
- Level 3가 정상 발동되면 **풀버스트 상태에 진입**한다.
- (10초 내에 Level 3가 발동하지 못하면 체인 종료 후 일반 전투로 복귀.)

### 3.4 풀버스트 진입
- Level 3 버스트가 정상 발동되면 풀버스트 상태에 진입한다.
- 풀버스트 상태는 **기본 10초** 유지된다.
- 풀버스트 동안 전용 버프 및 효과가 적용된다.


### 3.5 예외 케이스
- 버스트 가 A(all)인 니케 레드 후드의 경우 버스트 1,2,3 니케 조건에 모두 해당하지 않는다. 단 레드후드는 모든 버스트 단계에서 버스트 스킬을 사용할 수 있으며 각 효과는 해당 니케의 스킬 규칙을 따른다.

## 4. 예외 규칙

### 4.1 버스트 재진입(Re-entry)
재진입 스킬을 가진 니케는 **동일한 버스트 레벨을 한 번 더** 사용할 수 있게 만든다.

- Level N 재진입 스킬을 가진 니케가 버스트를 사용하면, **동일한 버스트 레벨 N의 니케가 버스트를 사용** 하여야 다음 단계로 진행된다.
- 즉 재진입 B1 > B1 > B2 > B3로 진행된다.
- B2인 경우 B1 > 재진입 B2 > B2 > B3 로 버스트가 시전되며 스쿼드 내에 다른 B2 니케가 존재 하지 않으면 버스트 단계가 넘어가지 않는다.
- 재진입 스킬을 가졌더라도 해당 니케가 쿨타임이면 발동하지 않는다.
- 재진입 니케에게도 **우선순위 규칙이 동일하게** 적용된다.
- 재진입 발동 여부는 니케마다 **독립적**이다. 재진입 니케가 여러 명이면 각자 발동/미발동할 수 있으며, 발동한 수만큼 같은 레벨 버스트가 누적 연쇄된다. (별도 상한 없음 — 팀 내 해당 레벨 재진입 니케 수만큼 가능)

#### 우선순위 상호작용 예시
- 1번이 Level 1 **재진입** 스킬, 2번이 Level 1 일반 스킬:
  → 1번 발동(재진입) → 2번 발동 → (Level 2로 진행)
- 1번이 Level 1 일반 스킬, 2번이 Level 1 **재진입** 스킬:
  → 1번 발동 → 2번은 발동하지 못하고 Level 2로 넘어감
  *(재진입은 "다른 니케가 한 번 더 쓰게" 하는 효과이므로, 앞선 니케가 재진입이 아니면 뒤 니케의 재진입은 트리거되지 않음)*

#### 재진입 누적 예시 (Level 1 재진입 니케 3명)
- 3명 모두 발동 시: `L1(재진입) → L1(재진입) → L1 → L2` 순서로 진행 가능
  → 재진입이 2회 이루어져 Level 1이 총 3회 연쇄된 뒤 Level 2로 넘어감
- 각 재진입 니케는 재진입을 사용하지 않을 수도 있으며(쿨타임 등), 2명만 발동하는 경우도 동일한 방식으로 처리한다.

### 4.2 풀버스트 시간 변경
풀버스트 시간을 늘리거나 줄이는 스킬을 가진 니케가 있는 경우:
1. 해당 니케의 풀버스트 시간 변경 **트리거 조건**을 확인한다. (트리거는 니케 JSON에 정의)
2. 트리거가 발동하면 풀버스트 시간이 변경된다.

## 5. 시뮬레이션 시스템

### 5.1 기본 설정
- 시뮬레이션 시간: **180초(3분)** 기준
- 타겟: **1개 고정**, 움직이지 않는 대상
- 데미지 누적: **프레임/틱 단위**, **60fps** 기준

### 5.2 버스트 게이지 처리
> 인게임 게이지 충전 공식은 확인 불가하므로, 게이지 충전 관련 스킬은 시뮬레이션에 적용하지 않는다. 대신 풀버스트 사이 간격을 고정 시간으로 정의한다.

- 풀버스트 사이 게이지 충전 시간: **기본 4.58초**
  - 사용자가 임의로 변경 가능
  - **2.52초 미만 값은 입력 불가** (하한선)
  - 하한 근거: `Full Burst Time 10s − 쿨타임 감소 스킬 최대치 7.48s = 2.52s`
- 전투 시작 시 게이지는 100%가 아니므로, 입력된 충전 시간을 적용한다.
  - **예외:** 전투 시작(타겟 등장) 시 게이지를 100%로 만드는 니케가 있으면 초기 충전 시간을 적용하지 않는다.
- 게이지가 100%여도 버스트 스킬이 쿨타임이면 발동하지 않는다.

> ⚠️ 이 게이지 로직은 오류 발생 여부에 따라 추후 변경될 수 있다.

## 6. 전투 순환 흐름 요약

```
1. 일반 전투 진행 (게이지 충전)
2. 버스트 게이지 100% 도달
3. Level 1 버스트 발동  (재진입 시 같은 레벨 추가 발동)
4. Level 2 버스트 발동  (재진입 시 같은 레벨 추가 발동)
5. Level 3 버스트 발동  (재진입 시 같은 레벨 추가 발동)
6. 풀버스트 10초 유지 (변경 트리거 시 시간 조정)
7. 일반 전투 복귀
8. 반복
```

- 각 버스트 레벨 단계에서 **최대 10초** 대기 내에 다음 레벨이 발동되지 않으면 체인 종료 → 일반 전투 복귀.
