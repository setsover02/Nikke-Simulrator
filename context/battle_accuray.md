
# 명중률
인게임에서 검은 원으로 총알의 탄착 범위가 표시됩니다. 이 검은 원을 편의상 명중률이라고 부르겠습니다. 이 명중률 내에 랜덤하게 총알이 발사되어 적 또는 코어 명중 여부가 결정됩니다. 명중률이 클 수록 원하는 곳에 총알을 맞출 확률이 낮아지며 명중률이 작아질수록 원하는 곳에 (예를 들어 코어) 정확하게 총알을 맞출 확률이 높아집니다.
- 명중률은 무기 종류에 따라 결정됩니다. (리서치 필요)
- 명중률은 스킬에 따라 증가하거나 감소할 수 있습니다.
- 명중률은 장비에 따라 증가하거나 감소할 수 있습니다.
- 장비나 스킬로, 큐브로 인해 명중률이 증가할 경우 명중률 범위 (검은 원)이 작아지는 것으로 간주합니다.
- 스킬로 인해 명중률이 감소할 경우 명중률 범위 (검은 원)이 커지는 것으로 간주합니다.

이 시뮬레이션에서는 다음과 같이 판단합니다.
- 샷건 캐릭터를 제외하고 빗나가는 공격은 없는 것으로 판단함.
- 명중률이 감소하는 경우 일반 공격 확률이 높아짐
- 명중률이 증가하는 경우 코어가 있는 적에 한하여 코어 히트 확률이 높아짐
- 타겟이 가까울 경우 명중률이 증가하며 타겟이 먼 경우 명중률이 감소합니다. 이는 선택한 교전 거리를 따릅니다.
  - Near
  - Mid
  - Far
> 실제 인게임과 동일하게 구현하기는 어려우므로 최대한 근사값을 찾아야 합니다. (리서치 필요)

## 구현 계획 1
- 명중률을 무기별로 0% - 100% 사이의 값으로 정의
- 100%인 경우 모든 공격이 코어 히트 또는 코어 크리티컬 공격인 것으로 계산함
- 0% 인경우 모든 공격이 일반 공격, 크리티컬 공격으로 계산함
- 0% < 명중률 < 100% 인경우, 명중률에 비례하여 코어 히트 확률이 증가함
> 단점: 인게임과 다름, 장비등으로 얻는 명중률 계산 처리 방식 적용 힘듬

## 구현 계획 2
- 탄착점을 “원 내부 랜덤 좌표”로 뽑는다.
```
r = R * sqrt(random())
θ = random() * 2π
x = r * cos(θ)
y = r * sin(θ)
```

- 명중 여부 판정
적 히트박스 반지름 = `hitRadius`
```
function isHit(radius: number, hitRadius: number) {
  const p = randomInCircle(radius);

  return (p.x*p.x + p.y*p.y) <= hitRadius*hitRadius;
}
```
