# 정의
캐릭터별 특수한 상태를 나타내는 변수를 정리한다.
작성 규칙은 [ 변수명: 인게임 툴팁 (부가설명)]의 형식으로 작성한다.
* 시전자: 해당 스킬을 시전하는 니케를 기준으로 한다.
* 아군: 스쿼드, 팀에 포함된 아군을 말한다.
* 아군 n기에게 라는 툴팁은 시전자 본인을 포함한다
* 최종 이라는 툴팁이 있는 경우 해당 니케에게 버프가 적용된 상태의 공격력, 방어력, 체력을 기준으로 한다.
* 시전자 기준 (체력, 공격력, 방어력) 증가 스킬은 스킬을 시전하는 니케의 스탯 수치를 기준으로 한다.

## 주요 고유 상태 (status)
bubble: 버블 (리틀 머메이드 전용 상태)
sword_coin: 소드 코인 (루주 전용 상태)
shield_coin: 실드 코인 (루주 전용 상태)
double_sword_coin: 더블 소드 코인 (루주 전용 상태)
youth_record: 청춘의 기록 (아르카나: 포춘 메이트 전용 상태)
happy_memories: 행복한 기억 (아르카나: 포춘 메이트 전용 상태)
precious_memories: 소중한 추억 (아르카나: 포춘 메이트 전용 상태)
leaving_memories: 추억 남기기 (아르카나: 포춘 메이트 전용 상태)
capture_chain: 포획 사슬 (미하라: 본딩 체인 전용 상태)
chain_binding: 사슬 감기 (미하라: 본딩 체인 전용 상태)
chain_pull: 사슬 당기기 (미하라: 본딩 체인 전용 상태)
relax: 휴식/릴렉스 (크라운 전용 상태)
target_extermination: 타겟 섬멸 (D: 킬러 와이프 전용 표식 디버프)
perfect_maid: 완벽한 메이드 (에이드 전용 상태)
nano_coating: 나노 코팅 (킬로 전용 보호막 상태)
matter_gamma: 매터 감마 (마나 전용 상태)
matter_sigma: 매터 시그마 (마나 전용 상태)
guts: 근성 (목단 전용 단계별 버프 상태)
strawberry_candy: 딸기 사탕 (디젤 전용 상태)
refresh_heart: 리프레쉬 하트 (페퍼 전용 상태)
hacking_code_collection: 해킹 코드 수집 (엑시아 전용 상태)
hero_vision: 히어로 비전 (라플라스 전용 상태)
blood_fiend: 피의 마인 (파워 전용 상태)
roar: 포효 (레오나 전용 상태)
b_mode: B 모드 (A2 전용 모드 상태)
stealth: 은신 (로산나 전용 상태)
virus_transfer: 바이러스 전이 (하란 전용 지속 피해 상태)
ice_witch: 빙결의 마녀 (에밀리아 전용 상태)
golden_chip: 골든 칩 (소다: 트윙클링 바니 전용 상태)
time_extension_1: 시간 연장 I (소다: 트윙클링 바니 전용 상태)
time_extension_2: 시간 연장 II (소다: 트윙클링 바니 전용 상태)
cry_of_victory: 승리의 외침 (클레이 전용 상태)
boom_install: 붐 인스톨 (일레그 전용 상태)
cummulative_explosion: 누적 폭발 스킬 (트로니 전용 누적 대미지 상태)
