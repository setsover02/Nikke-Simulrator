# 장비
## 장비, 오버로드로 인해 변경되는 스탯
고정 수치로 증가하는 장비 스탯은 이 시뮬레이션에서 따로 합산하지 않습니다.
- atk: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.
- defense: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.
- hp: 장비로 인해 변경되나 이 시뮬레이션에는 사용자가 직접 입력하므로 반영하지 않습니다.

아래의 값은 사용자가 장비 정보에 직접 입력하여 수치를 적용합니다.
사용자가 최댓값 보다 큰 숫자를 입력시 자동으로 최댓값으로 적용되도록 입력한 숫자를 바꿔줍니다.
- elementDamage: 우월코드 대미지 증가% (우코)
    - 최대값: 29.16 * 4 = 116.64

- accuracy: 명중률 증가% (명중률)
    - 최대값: 14.63 * 4 = 58.52

- maxAmmo: 최대 장탄 수 증가% (장탄)
    - 최대값: 85.37 * 4 = 341.48

- atkUp: 공격력 증가% (공격력)
    - 최대값: 14.63 * 4 = 58.52%

- chargeDamage: 차지 대미지 증가% (차댐)
    - 최대값: 14.63 * 4 = 58.52
    - 적용시 fullChargeDamage 가 더 늘어나는 식으로 적용됨
    - fullChargeDamage: 니케의 기본 스탯, 풀 차지 대미지
    test
    - 신데: fullChargeDamage: 200%, 소장품 배율 9.47% + 장비 차댐 5.47% = 224%
    - 루주: fullChargeDamage: 250%, 소장품 배율 9.47% + 장비 차댐 11.81% = 285%
    - 맥스웰: fullChargeDamage: 250%, 소장품 배율 6.31% + 장비 차댐 22.92% = 289%
    - 리버렐리오: fullChargeDamage: 250%, 소장품 배율 9.47% + 장비 차댐 7.59% = 281%
    - 앵커: fullChargeDamage: 250%, 소장품 배율 9.47% + 장비 차댐 9.7% = 283%
    - n102: fullChargeDamage: 350%, 소장품 배율 1.58% + 장비 차댐 0% = 356%

- chargeSpeed: 차지 속도 증가% (차속)
    - 최대값: 6.09 * 4 = 24.36
    - 해당 수치 만큼 차지 속도를 감소시킴

- criticalRate: 크리티컬 확률 증가% (크확)
    - 최대값: 7.07 * 4 = 28.28

- criticalDamage: 크리티컬 대미지 증가% (크댐)
    - 최대값: 20.36 * 4 = 81.44

- defense: 방어력 증가% (방어력)
    - 최대값: 14.63 * 4 = 58.52
