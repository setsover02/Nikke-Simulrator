# 전투 순환 로직 (완료)
## 기본 순환
전투는 크게 두 페이즈로 나뉩니다.
- 일반 전투 (Normal Phase)
- 풀버스트 (Full Burst Phase)
전투는 기본적으로 일반 전투 → 풀버스트 → 일반 전투 순환 구조를 따릅니다.

## 팀 구성과 자리 배치
- 팀은 최소 1명, 최대 5명의 니케로 구성됩니다.
- 각 니케는 1번부터 5번까지의 고정된 자리에 배치됩니다.
- 자리는 버스트 사용 우선순위를 결정하는 기준으로 사용됩니다.
- 번호가 낮은 자리에 배치된 니케일수록 높은 우선순위를 가집니다. 번호가 낮은 자리에 있는 니케가 버스트 사용 우선권을 가집니다.

### 버스트 우선순위 규칙
- 동일한 버스트 레벨 내에서 여러 니케가 사용 가능할 경우, 가장 낮은 번호 자리에 배치된 니케가 우선적으로 선택됩니다.
- 상위 우선순위 니케가 쿨타임 상태일 경우, 다음 순번 니케가 선택됩니다.
- 이 규칙은 버스트 레벨 1, 2, 3에 모두 동일하게 적용됩니다.

## 버스트
### 버스트 레벨
모든 버스트 스킬은 다음 중 하나의 레벨을 가진다.
- Level 1
- Level 2
- Level 3
각 버스트 스킬은 니케 별로 각 json에 작성된 쿨타임을 적용합니다.

### 버스트 발동 조건
- 버스트 게이지가 100%가 되었을 때만 버스트 스킬을 사용할 수 있다.
- 버스트 게이지가 100%가 되면 버스트는 자동으로 발동된다.
- 버스트 게이지가 100% 상태인데 버스트 스킬이 쿨타임인 경우 쿨타임 시간동안 대기하며 버스트 게이지는 100%로 유지된다. 이후 쿨타임이 끝나면 버스트 스킬이 발동한다.
- 수동 조작에 의한 발동은 고려하지 않는다.

### 버스트 체인 규칙
버스트는 반드시 Level 1 → Level 2 → Level 3 순서로 연결된다.

#### Step 1: Burst Level 1
게이지가 100%가 되면, 사용 가능한 쿨타임이 아닌 Level 1 니케 중 우선순위가 가장 높은 니케가 발동한다.
- Level 1 버스트 스킬을 사용한 니케의 버스트 및 스킬 버프가 적용된다.
- Level 1 발동 후 최대 10초 동안 대기 상태에 진입한다.
- 대기 시간 내에 쿨타임이 아닌 Level 2 니케가 존재하면 즉시 발동한다.
- 10초 내에 발동하지 못할 경우 체인은 종료되고 일반 전투로 복귀 하여 다시 버스트 게이지를 충전한다.
- Level 2 버스트 스킬을 사용한 니케의 버스트 및 스킬 버프가 적용된다.

#### Step 3: Burst Level 3
- Level 2 발동 후 최대 10초 동안 대기 상태에 진입한다.
- 대기 시간 내에 쿨타임이 아닌 Level 3 니케가 존재하면 즉시 발동한다.
- 10초 내에 발동하지 못할 경우 체인은 종료되고 일반 전투로 복귀 하여 다시 버스트 게이지를 충전한다.
- 이 때 버스트를 사용한 니케의 버스트 스킬 버프가 적용된다.

### 풀버스트 진입
- Level 3 버스트가 정상적으로 발동되면 풀버스트 상태에 진입한다.
- 풀버스트 상태는 10초간 유지된다.
- 풀버스트 동안 전용 버프 및 효과가 적용된다.

### 버스트 재진입 예외 케이스
버스트 재진입 스킬을 가진 니케의 경우 동일한 버스트 레벨을 한번 더 사용할 수 있습니다.
- Level 1 버스트 재진입 스킬을 가진 니케가 버스트를 사용하면 다른 니케의 Level 1 버스트를 한번 더 사용할 수 있습니다.
- Level 2 버스트 재진입 스킬을 가진 니케가 버스트를 사용하면 다른 니케의 Level 2 버스트를 한번 더 사용할 수 있습니다.
- Level 3 버스트 재진입 스킬을 가진 니케가 버스트를 사용하면 다른 니케의 Level 3 버스트를 한번 더 사용할 수 있습니다. 현재 Level 3 버스트 재진입 스킬을 가진 니케는 아직 없습니다.
- 버스트 재진입 스킬을 가졌더라도 쿨타임인 경우는 버스트 스킬이 발동하지 않습니다.
- 재진입 버스트를 가진 니케의 경우도 우선순위가 동일하게 적용됩니다.
    - 예시: 1번 자리의 니케가 버스트 재진입 스킬인 경우, 2번 자리의 니케가 같은 레벨의 버스트 스킬을 가졌다면 1번 자리의 버스트 스킬 사용 후 2번 자리의 니케가 버스트 스킬을 사용합니다. 만약 1번 자리의 니케가 Level 1 버스트 스킬, 2번 자리의 니케가 같은 레벨의 재진입 버스트 스킬이라면 1번 자리의 니케가 버스트 스킬 사용 후 2번 자리의 니케는 버스트 스킬을 사용하지 못하고 Level 2 버스트 스킬로 넘어갑니다.
- 재진입 버스트 스킬을 가진 니케가 3명인 경우
    - Level 1 재진입 버스트 → Level 1 재진입 버스트 → Level 1 → Level 2 이런 순서로도 가능합니다.

### 풀버스트 시간 예외 케이스
풀버스트 시간 자체를 늘리거나 줄이는 스킬을 가진 니케가 있는 경우
- 해당 캐릭터의 풀버스트 시간을 늘이거나 줄이는 트리거를 확인합니다.
- 트리거가 발동하면 풀버스트 시간이 변경됩니다.

### 전투 순환 흐름 요약
1. 일반 전투 진행
2. 버스트 게이지 100% 도달
3. Level 1 버스트 발동 (가능한 경우)
4. Level 2 버스트 발동 (가능한 경우)
5. Level 3 버스트 발동 (가능한 경우)
6. 풀버스트 10초 유지
7. 일반 전투 복귀
8. 반복


# 시뮬레이션 시스템

## 기본 설정
- 시뮬레이션 시간은 180초 (3분)을 기준으로 합니다.
- 타겟은 1개로 고정하며 움직이지 않는 타겟을 대상으로 합니다.
- 데미지는 프레임/틱 단위로 누적 계산합니다.
    - 60fps를 기준으로 합니다.

## 버스트 게이지
버스트 게이지 계산 공식은 인게임에서 확인할 수 없으므로 게이지 충전과 관련된 스킬 등은 이 시뮬레이션에서 적용하지 않습니다.
단 Full Burst 사이에는 다음과 같은 규칙을 적용합니다.
- 버스트 게이지 충전을 위해 4.58초를 소모하는 것으로 정의합니다. 이 수치는 사용자가 임의로 바꿀 수 있도록 하며 2.52초 보다 작은 값은 입력하지 못하도록 합니다.
- 전투를 시작시 버스트 게이지가 100%가 아니므로 입력한 버스트 게이지 충전 시간을 적용합니다.
    - 만약 전투 시작 시, 타겟 등장 시 버스트 게이지를 100%로 만드는 니케가 있다면 버스트 게이지 충전시간을 적용하지 않습니다.
- 버스트 게이지가 100%이더라도 버스트 스킬이 쿨타임인 경우 버스트 스킬이 발동하지 않습니다.
- 최소값은 Full Burst Time 10s - 버스트 스킬 쿨타임 감소 스킬의 최대치인 7.48s = 2.52s 이므로 위와 같이 적용합니다.
> 이 로직은 오류 발생 여부를 판단하고 추후 변경될 수 있습니다.
