# UI Development Rules

- 새 컴포넌트를 만들기 전에 기존 컴포넌트를 먼저 확인하고 재사용한다.
- 새 CSS 클래스를 만들기 전에 기존 클래스와 스타일을 확인한다.
- 색상, 간격, 크기 등의 값은 기존 변수와 디자인 토큰을 우선 사용한다.
- 기존 컴포넌트로 해결 가능하면 새 컴포넌트를 만들지 않는다.
- 필요한 경우 새로 만들기보다 기존 컴포넌트의 확장이나 조합을 우선한다.
- TSX에서 인라인 스타일 사용은 최대한 지양하고 CSS/SCSS 클래스를 사용한다.
- CSS 클래스 이름은 `card-frame`처럼 소문자와 하이픈(kebab-case)을 사용하며 대문자는 사용하지 않는다.
- UI 작업 순서는 Search → Reuse → Extend → Create를 따른다.
